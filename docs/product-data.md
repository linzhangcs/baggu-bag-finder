## Missing or ambiguous data

- Dimensions use BAGGU's source labels exactly. Some pages use `L`, some use `D`, and one Recycled Leather Bowler row appears as `4" 5.25" D`; this should be verified before using that leather row in UI.
- Weight is not listed for any supplied product page.
- Capacity or volume is not listed as a numeric volume for any supplied product page. Standard Baggu has a confirmed 40lb weight limit and 2-3 plastic grocery bag capacity.
- Strap or handle data is missing for Baby Baggu, Standard Baggu, and Big Baggu.
- Closure type is missing for Everyday Cloud Bag, Medium Nylon Crescent Bag, Standard Baggu, Baby Baggu, and Big Baggu.
- Book fit is not explicitly confirmed for any product.
- Extra layer or sweater fit is not explicitly confirmed. Big Baggu fits laundry and blankets, so `fitsExtraLayer` is set to true only for Big Baggu.
- Water bottle size is sometimes written as `32oz` and sometimes `32 oz`; preserve source wording in raw data.
- Loaf product details say it fits a water bottle, but the comparison section does not specify bottle size.
- The Cloud family appears travel-oriented based on Packing Cube Set and Dopp Kit fits, but Everyday Cloud Bag itself is not marked `goodForTravel` because its comparison fit list does not include travel-specific items.
- Source pages compare related products that are not necessarily the same style family, such as Loaf with Pochette and Bowler, or Meringue with Bowler and Shoulder Bag. Those are not treated as same-family size variants unless the product family itself is shared.
- Image URLs are BAGGU product-page CDN image references. Some related comparison variants use a different confirmed colorway image than the original source product page.
- Frontend `productUrl` values point to the correct BAGGU product size page for shopping navigation. `sourceUrl` remains the page where the product facts were confirmed.

## Potential size-finder recommendation attributes

Use these attributes as frontend inputs only after validating that the intended finder should compare across these product styles.

| Attribute          | Evidence-backed assignment guidance                                                                                                                                                                                                                                                                                        |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `carryLevel`       | Assign from BAGGU language and fit list only: essentials/minimal fit becomes `minimal` or `light`; everyday wording and standard everyday items become `everyday`; "more than essentials" or larger fit lists become `roomy`; groceries, laundry, blankets, carry-on, or 16" laptop sleeve support can be `high-capacity`. |
| `fitsPhone`        | true only when `phone` is listed in "what it fits" or product details.                                                                                                                                                                                                                                                     |
| `fitsWaterBottle`  | true only when water bottle is listed in product details or "what it fits"; preserve bottle size separately when stated.                                                                                                                                                                                                   |
| `fitsBook`         | unknown for current researched set.                                                                                                                                                                                                                                                                                        |
| `fitsTablet`       | true when BAGGU lists Puffy Tablet Sleeve.                                                                                                                                                                                                                                                                                 |
| `fitsLaptop`       | true when BAGGU lists a laptop sleeve or explicitly states laptop fit; store confirmed size such as 13/14" or 16".                                                                                                                                                                                                         |
| `fitsExtraLayer`   | true only for Big Baggu in the current data because blankets/laundry are explicitly listed. Other products remain unknown until BAGGU confirms sweater or layer fit.                                                                                                                                                       |
| `goodForTravel`    | true only when the BAGGU fit list includes travel-specific items such as Packing Cube Set or Dopp Kit.                                                                                                                                                                                                                     |
| `goodForGroceries` | true for Standard Baggu based on the full-load grocery and 2-3 plastic grocery bag claims.                                                                                                                                                                                                                                 |

The current six supplied product pages are useful for a size finder, but they are not a single clean size ladder. Crescent, Bowler, Cloud, Meringue, and reusable Baggu each have their own sizing context. Standard Baggu and Cloud Carry-On style products serve fundamentally different use cases than small purses or everyday crossbody bags, so a recommendation model should distinguish product family, size within family, and carrying capacity.
